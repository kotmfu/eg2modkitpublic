# Subtitles (`SUBS`)

Part of the [file format reference](../REFERENCE.md): [4.37 GUI, fonts, input and stats](../REFERENCE.md#437-gui-fonts-input-and-stats).

**Subtitles (`SUBS`, `misc\common.asr`, 1, 45 bytes).** `[u32 1][u32 0][u8 1]` + 9 f32: 0.05, 1, 0.37, 0.30, 0.48,
0.41, 0.28, 0, 1. Field meanings are unread.
