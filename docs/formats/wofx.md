# Vignette (`WOFX`)

Part of the [file format reference](../REFERENCE.md): [4.34 Island level chunks and entities](../REFERENCE.md#434-island-level-chunks-and-entities).

**Vignette (`WOFX`, islands, two per island).** `[u32 2][u32 0][u32 KeyHash("Island_Vignette_FullView")][f32 1]` +
two RGBA byte colours `00 ff ff 00`. The name is a full-screen effect in the island's `FSX2`. All eight are identical.
